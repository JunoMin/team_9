# 엑셀 기반 건축 규제 연결

검색 결과의 **건축 규제 보기**는 선택한 `Land`를 받아 수집 엑셀에서 변환한
`src/data/regulations.generated.ts`와 연결합니다. API 키나 별도 서버 없이 GitHub Pages에서도 동작합니다.

## 연결 기준

1. 수의계약 필지: 시도 + 정확한 사업지구명 + 소재지 + 예정/확정지번 + 면적 일치.
2. 공고 필지: 공고 ID + 소재지 + 지번 + 면적으로 수집 필지 행을 찾고,
   엑셀에 기록한 원본 행 연결을 사용합니다.
3. 후보가 여러 개이거나 지번이 비어 있으면 숫자를 선택하지 않습니다.
   대시(`-`)는 지번이 아닙니다. `638-0`과 `638`만 같은 본번으로 취급하고,
   `12-34`와 `123-4`는 구분합니다. 가격은 변동할 수 있어 식별자로 쓰지 않습니다.
4. 공고 ID가 같은 원문과 엑셀의 같은 지역·지구 관련 공고는 참고자료로 제공합니다.
   지구명 부분일치 검색으로 건폐율·용적률을 적용하지 않습니다.

동일 필지가 확인되면 **선착순원본**의 용도지역·공급용도·건폐율·용적률·최고층수를
보여줍니다. 허용/불허용도와 최고높이는 필지별 근거가 없으면 확인 필요 또는 자료 없음으로 표시합니다.
원본 0은 무제한으로 바꾸지 않습니다. 검색 데이터와 규제 수치가 다르면 두 값을 함께 표시합니다.

**규제정리_3건**의 6개 행은 블록 단위 PDF 발췌입니다. 지번과 블록의 검증된 대응표가
없으므로 펼쳐 보는 참고 표로 제공하고, 필지의 확정 규제값으로 사용하지 않습니다.
근거 조문, PDF/인쇄 페이지, 예외조건, 최신성 확인 상태와 원문 링크를 함께 제공합니다.
ZIP 내부 문서는 ZIP 원본을 열어 확인하도록 표시합니다. 사용자 PC의 로컬 경로는 배포 데이터에 넣지 않습니다.

## 엑셀 갱신

Python 3와 `openpyxl`이 필요합니다. 원본 엑셀은 읽기만 하고 변경하지 않습니다.

```bash
python -m pip install -r scripts/requirements-regulations.txt
python scripts/import-regulations.py /path/to/LH_토지매각_지역별_공통양식_수집대장.xlsx --as-of 2026-11-13
pnpm check
```

필수 시트명과 열 이름이 달라지면 변환이 오류로 중단됩니다. 생성 파일에는 파일명,
SHA-256, 수집일, 선착순 원본 행과 출처 URL이 남습니다. 수집일은 최신 고시의 시행일이 아닙니다.
엑셀 파일이나 수 GB의 원문 묶음을 저장소에 올릴 필요는 없습니다.

현재 스냅숏: 선착순 원본 1,625행, 수집 공고 99건(조회기간 88건 + 이전 참고 11건),
공고 필지 1,020행, 시행지침·계획자료 231행, 3개 지구의 규제 표본 6행.
세종 외부 로그인 필요 자료는 수집 제외 상태를 유지합니다.

향후 정확도를 높이려면 `PNU`(필지 고유번호)와 **사업지구 → 블록 → 필지** 대응표,
지침의 고시번호·시행일·개정 이력을 추가합니다. 현재 자료에 없는 PNU나 적용 블록은 생성하지 않습니다.
