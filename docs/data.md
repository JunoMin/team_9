# LH 토지 데이터

화면은 GitHub Pages(정적 호스팅)에서 동작하므로, 브라우저가 LH API를 직접 부르지 않습니다.
인증키가 있는 사람이 `pnpm data:lh`로 스냅숏을 만들어 커밋하고, 화면은 그 파일을 읽습니다.

## 갱신 방법

1. `.env.example`을 `.env`로 복사하고 `LH_SERVICE_KEY`에 공공데이터포털 인증키(Decoding)를 넣습니다.
2. `pnpm data:lh` 실행 → `src/data/lhLands.generated.ts`가 다시 만들어집니다.
3. `pnpm check` 후 `chore/lh-data-YYYYMMDD` 같은 브랜치로 PR을 올립니다.

생성 파일은 직접 고치지 않습니다. 필지 하나가 한 줄이라 PR diff에서 추가·삭제된 필지를 바로 볼 수 있습니다.

## 출처와 범위

| 출처                                                   | 포함 범위                                        | 가격                             |
| ------------------------------------------------------ | ------------------------------------------------ | -------------------------------- |
| `lhLeaseNoticeInfo1` → `lhLeaseNoticeSplInfo1`         | 최근 6개월 토지 공고 중 공고중·접수중·정정공고중 | 입찰은 예정가격, 추첨은 공급가격 |
| LH청약플러스 선착순(수의)계약 > 토지 (`dsDbsListJson`) | 전국 수의계약 토지                               | 공급가격                         |

가격이나 면적이 비어 있는 필지는 조건 검색에 쓸 수 없어 제외합니다.
수의계약 목록은 OpenAPI가 아니라 웹 페이지에 들어 있는 값이므로, 페이지 구조가 바뀌면 스크립트가 오류로 멈춥니다.

## `Land` 매핑

| `Land` 필드 | 값                                                                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| `region`    | 시도 id (`gyeonggi`, `chungnam` …). 원본이 시군구를 일정하게 주지 않아 시도 단위입니다.                 |
| `purpose`   | 용도명 묶음: `detached`, `detached-shop`(점포겸용), `neighborhood`, `commercial`, `industrial`, `other` |
| `useName`   | 원본 용도명 그대로 (예: `실수요자택지 주거전용`)                                                        |
| 나머지      | 주소·지번·공고명·마감일·상세 링크·수의계약 문의 전화 (모두 선택 필드)                                   |

규칙은 `src/data/lhMapping.ts`에 있고 `tests/lhMapping.test.ts`가 검사합니다.

## 화면 연결

- 검색 선택지(`src/config/searchSteps.ts`)는 이 데이터에서 지역·용도별 필지 수를 세어 만듭니다. 판매 중인 필지가 없는 시도는 선택지에 나오지 않습니다.
- 선택한 필지를 A02·A03에 넘기는 형식은 [handoff.md](handoff.md)에 있습니다.
- 스냅숏을 번들에 직접 넣어 JS가 약 1.8MB(gzip 약 70KB → 145KB) 늘었습니다. 문제가 되면 `public/`의 JSON을 지연 로딩하는 방식으로 바꿉니다.
